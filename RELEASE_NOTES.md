# 🐯 Cekcok Super App v0.1.0 Release Notes

### ✨ Highlights
- **🐯 Brand New Mascot**: Iconic Macan Cisewu emblem with clean macOS taskbar squircle and transparent background.
- **🚀 Super App Pivot**: 4-in-1 Workspace Suite (Monaco Code IDE, Fortune Sheet Excel, BlockNote Word Document, and Tldraw Drawing Whiteboard).
- **⚡ Monaco Multi-Pane Splitting**: 4-way visual drop zones, tab state preservation, and custom pointer drag-and-drop.
- **💻 Rich Bottom Panel**: Real-time Problems diagnostics, filterable Output channels, Node/JS Debug REPL, Streaming Multi-Terminal PTY, and local Ports viewer.
- **📦 Git & Node.js Tooling**: Native source control diffs, one-click commit, and npm package scripts runner.
- **⏳ Fast Boot & Lazy Loading**: Code-splitting via React.lazy + Suspense with animated shimmer skeleton loaders.
- **🔄 Tauri v2 Auto-Updater**: Silent background update checks, in-app progress bar, and 1-click update/restart.
- **🚢 Automated MinIO Deployment**: One-command release pipeline via `npm run deploy`.
